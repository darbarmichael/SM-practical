Practical No. 3 
                           Data collection using Twitter API. 
 
AIM: To collect recent public posts from Twitter/X using its API and store selected fields for 
social media analysis. 
 
Theory: An API (Application Programming Interface) allows a program to request data from 
a service in a structured way. The Twitter/X API can provide public post data when the 
required developer access and permissions are available. 
 
Program: 
File name: Twitter.py 
 
import tweepy 
import pandas as pd 
 
bearer_token = "Paste Your API Token" 
 
client = tweepy.Client( 
    bearer_token=bearer_token, 
    wait_on_rate_limit=True 
) 
 
query = "digital marketing -is:retweet lang:en" 
 
data = [] 
 
try: 
    response = client.search_recent_tweets( 
        query=query, 
        max_results=20, 
        tweet_fields=["created_at", "public_metrics", "author_id"] 
    ) 
 
    if response.data: 
        for tweet in response.data: 
            data.append({ 
                "Tweet": tweet.text, 
                "Date": tweet.created_at, 
                "Author ID": tweet.author_id,
                "Likes": tweet.public_metrics["like_count"], 
                "Retweets": tweet.public_metrics["retweet_count"], 
                "Replies": tweet.public_metrics["reply_count"] 
            }) 
    elif response.errors: 
        print("Twitter API returned errors:") 
        for error in response.errors: 
            print(error) 
    else: 
        print("No tweets found for the current query.") 
 
except Exception as e: 
    print("Twitter API request failed.") 
    print(f"Reason: {e}") 
    print("Check your internet connection, bearer token, and Twitter API access.") 
    raise SystemExit(1) 
 
df = pd.DataFrame(data) 
 
print(df) 
 
df.to_csv("twitter_data.csv", index=False) 
 
print("\nData collected successfully.") 
 
 
Commands to Execute: 
pip install tweepy pandas 
python Twitter.py

When the script works successfully, it will print the tweet data in a table format and save it as 
a CSV file named twitter_data.csv in the same folder. However, in the current run, the script 
did not fetch data because the Twitter API is Paid and it shows Timed out, so the terminal

Practical No. 4 
Data collection using web scraping (BeautifulSoup). 
AIM: To collect structured text data from a webpage using Python requests and 
BeautifulSoup. 
Theory: Web scraping means programmatically reading information from webpages. The 
requests library downloads the webpage response, while BeautifulSoup parses the HTML and 
provides methods for finding tags and extracting text. Scraping should respect a website’s 
terms, robots rules, rate limits and access restrictions. Only publicly accessible and permitted 
content should be collected. 

Program: 
File name: Webscraping.py 

import requests 
from bs4 import BeautifulSoup 
url = "https://www.paruluniversity.ac.in/" 
response = requests.get(url) 
soup = BeautifulSoup(response.text, "html.parser") 
print("Title:", soup.title.string if soup.title else "No Title") 
h1_tags = soup.find_all("h1") 
print("H1 Count:", len(h1_tags)) 
for h1 in h1_tags: 
     print("H1:", h1.get_text(strip=True)) 
meta_tags = soup.find_all("meta") 
print("Meta Tags Count:", len(meta_tags))

Practical No. 5 
Data preprocessing using Pandas - Cleaning and Standardization. 
 
AIM: To clean and standardize a small social media dataset using Pandas. 
 
Theory: Raw social media data can contain extra spaces, inconsistent capitalization, duplicate 
rows and empty values. Pandas provides Data Frame operations for cleaning and transforming 
tabular data. Cleaning before analysis improves the consistency of later tokenization, sentiment 
analysis and visualization. 
 
Program: 
File Name: Clean.py 
 
import pandas as pd 
 
data = { 
    "user": ["Aman", "Riya", "Aman", "Kabir"], 
    "text": [ 
        " AWS is GREAT! ", 
        "Good cloud session", 
        " AWS is GREAT! ", 
        None 
    ] 
} 
 
df = pd.DataFrame(data) 
 
df = df.drop_duplicates() 
df["text"] = df["text"].fillna("") 
df["text"] = df["text"].str.strip().str.lower() 
 
print("Cleaned Data:") 
print(df)

Duplicates and Data Types 

AIM: To perform common preprocessing operations such as missing-value handling, 
duplicate removal and data-type conversion using Pandas. 
Theory: Preprocessing converts raw data into a consistent form suitable for analysis. Missing 
values can be removed or replaced depending on the purpose of the dataset. Duplicate records 
may distort frequency and sentiment results. Pandas also supports conversion of columns to 
numeric or datetime types, which is useful for filtering and visualization. 

Program: 
File name: Data.py 

import pandas as pd 
df = pd.DataFrame({ 
"post": ["Good product", "Bad service", "Good product", None], 
"likes": ["10", "5", "10", "3"] 
}) 
print(df.info()) 
df = df.drop_duplicates()

df["likes"] = pd.to_numeric(df["likes"], errors="coerce") 
df["likes"] = df["likes"].fillna(0) 
df.to_csv("processed_social_data.csv", index=False) 
print(df)

Practical No. 7 
Tokenization and Stop Word Removal 
AIM: To tokenize text into words and remove common stop words using NLTK. 
Theory: Tokenization breaks a sentence into smaller units called tokens. Word tokenization is 
commonly used before text classification and sentiment analysis. Stop words are frequently 
occurring words such as “the”, “is” and “and” that may contribute less information in some 
text-mining tasks. Stop-word removal is task-dependent and should not be applied blindly 
because some common words can carry meaning in sentiment or context. 

Program: 
File name: nltk_demo.py 

import nltk 
from nltk.tokenize import word_tokenize 
from nltk.corpus import stopwords 
nltk.download("punkt") 
nltk.download("punkt_tab") 
nltk.download("stopwords") 
text = "This is a very useful cloud computing course." 
tokens = word_tokenize(text) 
stop_words = set(stopwords.words("english")) 
filtered = [ 
word for word in tokens 
if word.lower() not in stop_words 
] 
print("Tokens:", tokens) 
print("After stop word removal:", filtered)

pip install nltk 
python nltk_demo.py

After stop word removal: ['useful', 'cloud', 'computing', 'course', '.']
